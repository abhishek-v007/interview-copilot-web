# Interview Copilot Web

Public web application for the interview preparation platform.

This project is independent from `interview-copilot-desktop` and `interview-copilot-api`. It contains **no Electron code** and does not call the AI backend in this version.

## Initial version

- Landing page
- Product explanation
- Interview preparation CTA
- Responsive layout
- Placeholder routes for later product areas

Not included yet: authentication, payments, database, AI calls, audio, WebSockets, or the live copilot overlay.

## Setup

```bash
cd interview-copilot-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
